# Data sources and cache tracking

No raw data are shipped with this package. The code reads caches from the research folder
(`USDJPY_RESEARCH_ROOT`, default `../data_review`) and licensed J-Quants data from a private folder
(`USDJPY_PRIVATE_DIR`). Offline use of these caches is the default; every acquisition function is off
unless its switch is set (see `usdjpy/sources.py`). No credential, authenticated URL or API key is
stored anywhere in the package.

Generated by `scripts/write_data_sources.py`; sizes in bytes, hashes SHA-256.

## Providers and access

| files | provider | access route | licence note |
|---|---|---|---|
| `shared_fmp_*` | Financial Modeling Prep (FMP) | Paid API. ETFs: /stable/historical-price-eod/dividend-adjusted; FX: /stable/historical-price-eod/full. API key from the macOS Keychain item 'fmp-market-data' (sources.fmp_keychain_key); requests counted in setup_research/request_ledger.json. | Subscriber terms; raw prices are not redistributed. |
| `shared_fred_*` | FRED, Federal Reserve Bank of St. Louis | Public CSV: https://fred.stlouisfed.org/graph/fredgraph.csv?id=<SERIES>. | Series-specific terms (for example VIX from Cboe, WTI from EIA); not redistributed here. |
| `jpy_mof_jgb*` | Ministry of Finance Japan | Public CSV: https://www.mof.go.jp/english/policy/jgbs/reference/interest_rate/historical/jgbcme_all.csv (reserved year: the current-month file as well). | Public government data. |
| `jpy_boj_*` | Bank of Japan time-series API | Public: https://www.stat-search.boj.or.jp/api/v1/getDataCode (FM01 STRDCLUCON for TONA; FM08 FXERD04 for the 17:00 JST USD/JPY fix). | Public central-bank data. |
| `jpy_cftc_*` | CFTC Traders in Financial Futures | Public Socrata API: https://publicreporting.cftc.gov/resource/gpe5-46if.csv (contract 097741, Japanese yen). | Public government data. |
| `jpy_fred_nikkei*` | FRED (NIKKEI225) | Public CSV: https://fred.stlouisfed.org/graph/fredgraph.csv?id=NIKKEI225. | Nikkei index terms; not redistributed here. |
| `bls_*` | U.S. BLS schedule pages via the Internet Archive | https://web.archive.org/ captures of bls.gov schedule pages. | Public. |
| `jquants_*` (private) | J-Quants (JPX Market Innovation & Research) | Licensed API https://api.jquants.com/v2/indices/bars/daily, codes 0000 (TOPIX), 008E (TOPIX-17 banks), 0088 (TOPIX-17 electric appliances & precision); key from the Keychain item 'jquant-market-data'; refresh only with CQF_JQUANTS_REFRESH=1. | Licensed. Raw rows and derived values stay in the private folder; only feature names, counts and these hashes appear here. |

The FMP daily close is provisionally treated as a 17:00 New York observation; the study states this
as an assumption. The provisional `available_time` values inside the observation files are replaced
by the availability rules of `usdjpy/timing.py` before any alignment.
